# Retro Page compatibility lab

Use the Windows 3.1 launcher to browse a live published member site, or open the included Late Night Signal export offline. The other platform directories include guest readers and launch instructions.

| Computer | What you can open | Launch guide |
| --- | --- | --- |
| Windows 3.1 | Classic HTML and GIFs in a 16-bit browser | [Windows 3.1](windows31/README.md) |
| Windows 98 SE | Classic HTML and its text edition in Internet Explorer 5 | [Windows 98](windows98/README.md) |
| Commodore 64 | A local PETSCII reader or a live two-way SwiftLink serial terminal in VICE | [Commodore 64](8bit/README.md) |
| Commander X16 | A native 40-column BASIC display of the text edition | [Commander X16](8bit/README.md) |
| ZX Spectrum Next | A keyboard-operated `.NEX` text edition in the Next emulator | [ZX Spectrum Next](8bit/README.md) |
| ZX Spectrum 48K | A 32-column text edition in a 48K machine snapshot | [ZX Spectrum 48K](8bit/README.md) |

The 8-bit readers are lab-built transfer files using the editor’s terminal output. The C64 gateway demonstrates sending the same page content over a local serial/TCP connection. The live emulator runs also covered public HTTPS via the host adapters. Physical hardware and telephone dial-in remain unverified.
