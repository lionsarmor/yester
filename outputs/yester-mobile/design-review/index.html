Phone browser controls

Back returns through interior pages and outside domains. Forward retraces that history, then becomes Next. Reload becomes Stop while loading. Swipe the bottom grip to discover a site. The page keeps ordinary scroll, typing and game gestures.

Tools holds Sound / Mute, Save / Saved, Share, Library and Discover. Library has Bookmarks and Travel log, including Clear recent. Discover has Shuffle, Play, Follow a ring and Search with Grub. The account control shows Sign in or the current profile.

Settings and creator tools
  • Frame cabinet. Preview the same page under every frame. Apply the selection and remember it on this device.
  • Startup. Open a random member or resume the last page. Choose the creator’s layout or the text edition.
  • Toolbar and gestures. Enable grip swipes, start folded, or hide after six idle seconds. Hold the toolbar open during address entry. Keyboard users retain Alt+L and navigation shortcuts.
  • Sound. Start each visit muted or enable site audio. Keep a one-tap mute control; stop the previous site when leaving.
  • Library and privacy. Enable or disable local travel history, clear recent visits and keep saved bookmarks.
  • Creator tools. Make your own site opens Retro Page. My Sites opens the creator’s existing projects.
