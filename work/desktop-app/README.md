# Retro Page desktop 0.14.1

The desktop package includes the Retro Page editor, starter projects, and built-in artwork. A modern browser displays its application window. It uses a local address on your computer and works offline from the first launch. Video Vault, GIFCities, remote players, and publishing use the internet.

## Install and launch

- **Windows x64**. Extract the complete Windows ZIP and double-click **Retro Page.exe**. Edge, Chrome, or Brave opens a dedicated editor window. Drop a saved project onto the launcher to open it.
- **Debian or Ubuntu**. Run `sudo apt install ./Retro-Page-0.14.1-all.deb` from the download folder. Open **Retro Page** from Applications, launch `retro-page`, or open a `.yst` project from the file manager.
- **Source edition for macOS, Linux, and Windows**. Extract the source ZIP and run `python3 app.py` from the Retro-Page folder (on Windows, use `py -3 app.py`). Python 3.9 or newer and a modern browser are required. Supply a project filename to open it. The launcher uses the default browser when it cannot find a browser with a dedicated application-window mode.

## Make and publish a site

Choose **File → New from template → Make an arcade** to name a club and start with Lantern Run or Pond Post. The project includes a linked game room, the cartridge, and an editable BBS guide. **Play the neighborhood** opens playable member sites while your project stays open.

Use the Pages, Objects, GIFs, and Video Vault tabs to build your site. **Options → HTML / CSS editor** adds a block with a sandboxed preview. **Edit BBS** opens the terminal screen painter. **Preview** shows the desktop, phone, classic, and text editions.

**File → Save project** opens a native save dialog in Edge, Chrome, and Brave. Other browsers download the editable `.yst` file. **File → Open project** reopens files from the web edition and previous Retro Page desktop releases. The desktop and web editions each keep a working draft in the browser profile used for that edition. Use a saved project to transfer the complete document between them.

**Publish** opens **What visitors will see**. Switch between Phone, Classic HTML, Text, and BBS, or edit a missing fallback. Choose **Continue to publish** to open the publishing details. Choose a site name and directory setting, then sign in with your YesterSites account. **File → Export website ZIP** saves a standalone copy of the published layouts, artwork, and terminal editions.
